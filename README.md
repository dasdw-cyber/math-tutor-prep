# 数学家教备课 · Math Tutor Prep

先排好课程，再按课次准备知识点、分层练习和逐题解析。

[查看完整规则](SKILL.md) · [复制通用指令](references/国内AI通用指令.md) · [查看内容标准](references/content-rules.md)

## 这是什么

准备一次家教课，往往要同时处理好几件事：安排课程、整理知识点、寻找例题、区分练习难度、补齐解析，再把这些内容排成方便使用的 Word。

材料找到了，还要判断知识点是否遗漏、题目是否重复、解析是否完整，以及学生当前能用哪些方法。

这个 Skill 面向小学、初中和高中数学家教备课场景设计。根据学生年段、授课范围、课次数和每次时长，先规划课程，再为教师选定的一节课制作配套材料。

> 先把课程安排清楚，再把每节课的知识、练习和解析配齐。

## 使用前后

| 你目前需要处理的事情 | Skill 帮你整理成 |
| --- | --- |
| 一段授课范围，尚未分配课次 | 分阶段、分课次的课程计划 |
| 分散的知识点、公式和例题 | 按本课主题组织的知识点资料 |
| 难度混杂、思路重复的练习 | 基础、中档、拔尖三档练习 |
| 需要逐题寻找出处的历年真题 | 已核对原题与来源的真题分区 |
| 分开整理的题目与答案 | 题号对应、附原题的逐题解析 |
| 反复复制与调整文档格式 | 样式统一的独立 Word 文件 |

材料由教师根据学生情况选用，课堂活动与时间安排可以调整。

完整交付需要相应环境支持资料检索、Word 文件生成和可编辑数学公式，具体能力以实际使用入口为准。

### 方式二：加载 Skill

保留 `math-tutor-prep` 的完整目录，在支持 Skill 的 AI 助手中加载；也可以让具备本地文件读取能力的助手先读取 `SKILL.md`。

支持按名称调用时，可以这样开始：


有教材目录截图、学生基础或家长反馈时，可以一起提供。助手先读取已有信息，再补问影响课程安排的关键缺口。

## 会得到什么

整个流程分两步交付：先确定课程计划，再制作选定课次的材料。

| 文件 | 内容 |
| --- | --- |
| **课程计划 Word** | 阶段总览，各课主题、目标、重点难点、活动及用时 |
| **知识点 Word** | 概念、公式、适用条件、典型例题及解析 |
| **练习题 Word** | 基础、中档、拔尖练习，以及核验后的历年原题 |
| **答案解析 Word** | 逐题重现原题，再给出思路、步骤和最终答案 |

课程计划经教师确认后单独导出。之后每次处理教师选定的一节课，生成该课的三份配套资料。

## 练习怎样安排

标准配置为 **45道生成练习＋10道历年原题**。

| 分区 | 数量 | 侧重点 |
| --- | --- | --- |
| 基础 | 15道生成题 | 单一知识点理解与直接应用 |
| 中档 | 15道生成题 | 知识关联与常规方法组合 |
| 拔尖 | 15道生成题 | 关系转换、推理或分类讨论 |
| 历年真题 | 最多10道核验原题 | 与本课范围相关的真实考试题目 |

各区包含单选、填空、多选和解答题，具体配额见 [内容与来源规则](references/content-rules.md)。

- **难度按思维要求区分**：考虑知识关联、方法选择与推理深度。
- **检查覆盖与重复**：围绕知识点、典型题型和主要解法安排练习。
- **使用对应年段的方法**：拔尖题同样遵循本次年段与授课范围。
- **原题逐题核验**：保留题干、条件、选项、必要图形及出处。
- **真题不足据实交付**：说明实际收录数量和题型缺额，生成题与原题分区标识。

知识点资料中的典型例题单独编号，不占上述练习配额。

## 备课怎样进行

1. **明确本次课程。** 提取学生年段、授课范围、课次数与单次时长。
2. **先给课程计划。** 展示整体安排和各课目标、重点难点、活动与用时。
3. **教师确认并选课。** 调整计划后导出课程计划，再选择一节课制作材料。
4. **组织单课内容。** 查阅相关正文，梳理知识点、题型、主要解法与练习安排。
5. **生成配套资料。** 制作知识点、练习题、答案解析三份独立 Word。
6. **检查对应与页面。** 核对题量、题号、解析完整性及文档显示。

课程活动与用时随内容安排，教师可以按自己的授课方式调整。

## 核心特点

- **课程与资料衔接**：先确定每节课的目标，再围绕目标准备内容。
- **知识点配有例题**：概念、公式和适用条件结合具体题目展开。
- **练习有明确梯度**：基础、中档、拔尖分别承担不同训练任务。
- **解析可以对照使用**：逐题附原题、思路、关键步骤与答案。
- **来源清楚**：生成题与历年原题分开标识，原题来源与解析来源分别记录。
- **Word 便于修改**：采用统一样式与原生可编辑数学公式。
- **保留教师选择空间**：材料供教师按学生情况组合使用。

知识内容优先参考匹配年段与范围的《五三》正文；需要替换时，使用实际可读、来源可核验的匹配资料，并说明实际来源。

材料用于辅助教师备课，授课前由教师复核题目、解法和答案。
