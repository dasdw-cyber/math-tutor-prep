# Word样式与页面检查

课程计划一份，单课知识点、练习题、答案解析各一份。生成器只渲染所传入的本课，不批量组织其他课次。

| 项目 | 基线 |
| --- | --- |
| 纸张 | A4纵向，单栏，四周2厘米页边距 |
| 正文 | 宋体12磅；西文及数字Times New Roman 12磅 |
| 标题 | 黑体18磅，居中，Word标题样式；分区黑体14磅，小标题宋体12磅加粗 |
| 颜色 | 标题和正文黑色；表格白底或浅灰表头，不靠颜色传递必要信息 |
| 间距 | 正文1.3倍行距、段后4磅；题间先用6磅；较高公式允许自然撑开，不使用会裁切公式的固定行高 |
| 数学 | 原生OMML，Cambria Math；不输出公式截图或未转换的LaTeX |
| 表格与来源 | 表格及来源文字先用11磅，列宽按内容分配，行高自然增长，表头跨页重复 |
| 页面 | 页脚居中页码10磅，不另设封面或重复页眉，不额外留答题区 |

课程计划先阶段总览，再逐课给目标、重点难点、活动及用时；知识点按知识点分节并配独立编号例题。练习分基础、中档、拔尖、历年真题专项，每区按单选、填空、多选、解答排列，整课连续编号；解析逐题完整重现同一批原题，后接思路、步骤与答案。

短选项可一行两个；长或复杂选项分行。短题干与选项尽量同页，长解析可在完整步骤间分页。标题与其后内容保持相邻；避免只剩一行答案单独成页，也不把所有长题锁在一页造成大段空白。必要图形保持比例并紧邻说明，不改变原题。

导出后逐页看乱码、公式裁切、选项分离、重叠、溢出及异常空白，修正后重新导出。适用的documents或docx技能可协助页面检查；按当前工具要求使用渲染路径，不能假装工具成功。若缺少依赖或权限，说明限制，不静默安装软件或发送文档到第三方网站。

用户不要求打印效果测试，也不将实物打印、灰度或黑白打印测试作为本版交付和封装前置；保留黑白友好样式即可。本版样式来自用户认可的预览，不代表所有公式、图形、软件和年段都已测试。
